# 稼ぎのトリセツ ― 1人でお金を稼ぐ道

副業・個人事業で稼ぐ方法を、1日1手法ずつ「取扱説明書」の形で整理する静的サイトです。GitHub Pages(`main` の `/docs`)で公開します。

## 構成

| パス | 役割 |
|---|---|
| `content/methods/<slug>.md` | 手法ページの原稿(これを書く) |
| `data/queue.json` | 追加予定の手法の一覧と順序 |
| `config/site.json` | サイト名、カテゴリ、アフィリエイトID、広告の設定 |
| `build.py` | 原稿から `docs/` を生成する(標準ライブラリのみ) |
| `docs/` | 生成されたサイト(直接編集しない。`assets/style.css` だけは手で編集してよい) |

## 毎日の追加手順(1日1手法)

1. `python3 build.py --next` で、次に追加する手法(slug、タイトル、カテゴリ)を確認する。
2. その手法を調べる。**公式の情報(サービスの規約・ヘルプ・手数料表、官公庁)を最優先**にし、確認できた事実だけを書く。
3. `content/methods/<slug>.md` を作る。書式は `content/methods/note-paid-articles.md` を見本にする。
4. `python3 build.py` を実行して `docs/` を再生成し、エラーがないことを確認する。
5. 変更をコミットして `main` に push する。

### ページの型(この順に書く)

1. 導入(2〜3文)
2. `## しくみ`
3. `## お金の流れ(手数料)` 手数料・価格などの数字(該当する手法のみ)
4. `## 収益のイメージ(計算例)` 実績ではなく、仮定を明記した計算例
5. `## 向いている人・向いていない人` 一般的な傾向だけ(特定の個人向けの判断は書かない)
6. `## 注意:損をしやすいポイント` 黄色と黒の注意枠になる
7. `## 始め方` 番号付きの手順になる
8. `## こんなときは`
9. 紹介本(メタ情報の `books`)と出典(メタ情報の `sources`)

### 書くときのルール

- **この公開リポジトリには、運営者個人への向き不向きや個人情報を書かない。** 向き不向きの評価は、非公開のArtifact側だけに載せる。
- 数字(手数料、価格、期間など)は、出典で確認できたものだけを書く。出典は `sources` に必ず載せる(1件もないとビルドが止まる)。
- 収益額は「できる」「稼げる」と断定しない。実績が確認できない場合は「調べた範囲では見つからなかった」と書く。
- 金額や規約は変わるので、メタ情報の `updated` に調べた日を入れる。
- 投資・税金は一般的な情報にとどめ、個別の助言や勧誘にしない。
- 「簡単」「誰でも」「確実」などの言葉は、使わない。
- 紹介する本は、書名・著者・ISBNを国会図書館サーチや書店のページで確認できたものだけにする。本の題名にある収益額は、成功例であることを注意枠に書く。
- 他の記事・本の文章をそのまま写さない。自分の言葉で書く。

### メタ情報の書式

```
---
title: 手法の名前
category: content   # content / skill / product / goods / invest / caution
summary: 一文の説明
cost: 初期費用
time_to_income: 収益化までの目安
skill: 必要なスキル
face: 顔出しの要否
risk: 2             # 1〜5。点が多いほど損をしやすい
risk_label: リスクの中身を一言で
updated: 2026-10-28
books:
- 書名 | 著者(出版社) | ISBN
sources:
- 情報源のタイトル | URL
---
```

## 公開前の準備(アフィリエイトと広告)

公開(GitHub Pagesの有効化)の前に、次を済ませます。

1. アフィリエイトに登録する。登録には審査があります。最初は、もしもアフィリエイトを経由するとAmazon・楽天の提携もまとめて申請できます。
2. 取得したIDを `config/site.json` の `affiliate.amazon_tag` に入れる。入れるまでは、紹介本は書名と著者だけが表示され、リンクは付きません。IDを入れて `python3 build.py` を実行すると、全ページの紹介本にリンクが付き、フッターに広告の表示も自動で入ります。
3. 広告を載せる場合は、広告会社から受け取ったコードを `config/ad-snippet.html` に貼り、`config/site.json` の `ads.enabled` を `true` にして再生成する。独自ドメインが必要な広告サービスもあるので、規約を確認する。
4. GitHubのリポジトリ設定で、Pagesの公開元を `main` の `/docs` にする。

## 確認

- `python3 build.py` が成功すること。
- スマホ幅(390px)で横にはみ出さないこと。
- 外部リンクの先が実在し、書いた内容と合っていること。
