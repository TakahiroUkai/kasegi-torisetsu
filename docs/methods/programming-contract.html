プログラミング受託は、依頼主から頼まれて、ウェブサイトやアプリ、業務ツールなどを作って納品する仕事です。先に押さえたい点は2つです。1つ目は、契約が「完成を約束するもの」なのか、「作業をすることを約束するもの」なのかで、引き受ける責任が変わること。2つ目は、フリーランスに仕事を頼む側には、条件を書面などで示す決まりがあることです。どちらも、公式の資料で確認できます。

しくみ

  • 依頼主から要望を聞き、見積もりと条件を決めて、プログラムを作り、納品します。確認が終わると、報酬が支払われます。
  • 契約の形によって、責任が変わります。経済産業省とIPA(情報処理推進機構)の「アジャイル開発外部委託モデル契約」は、準委任契約を前提にしています。この資料の契約条文には、「準委任契約であり、(受注側が)開発対象プロダクトの完成義務を負うものではないことを確認する」と書かれています。
  • 同じ資料の解説には、民法644条の「受任者は、委任の本旨に従い、善良な管理者の注意をもって、委任事務を処理する義務を負う」が引かれています。つまり、準委任では、完成を約束するのではなく、注意して作業を進めることが求められます。
  • 完成を約束する契約(一般に請負と呼ばれる形)もあります。この回は、請負の条文を一次情報で確認していません。自分の仕事がどちらの契約なのかは、契約書の文言で確認してください。
  • ガイドラインによると、「特定受託事業者に係る取引の適正化等に関する法律」(フリーランス・事業者間取引適正化等法)は、令和6年11月1日に施行されています。仕事を頼む事業者は、仕事の内容や報酬の額などを、書面または電磁的方法(メールなど)で、業務委託をした後に直ちに明示する決まりです。

お金の流れ(手数料)

報酬が入るまでの流れは、依頼主と直接契約する場合と、仕事を探すサービスを通す場合で変わります。サービスを通すと、報酬から手数料が引かれることがあります。手数料の率は、サービスによって違い、変わることもあります。この回は、特定のサービスの手数料を確認していないため、率は書きません。最新の率は、使うサービスの公式ページで確認してください。

また、ガイドラインによると、報酬の支払期日は、成果物を受け取った日から60日以内の、できる限り短い期間で決める必要があります。支払期日を決めていないときは、受け取った日が支払期日になります。60日を超えて決めたときは、受け取った日から60日を過ぎた日が支払期日になります。

収益のイメージ(計算例)

次の数字はすべて仮定であり、実績ではありません。1件の報酬を15万円とし、手数料を10%(仮定)、1件の作業時間を30時間(仮定)とします。

  • 手数料は15万円の10%で、15,000円です。
  • 1件の手取りは、150,000円−15,000円で、135,000円です。
  • 月に2件受けると、135,000円×2件で、270,000円です。
  • 作業時間は、30時間×2件で、60時間です。270,000円÷60時間で、1時間あたり4,500円です。
  • 修正や追加の作業で、1件の作業が40時間になると、135,000円÷40時間で、1時間あたり約3,375円です。報酬の額が同じでも、作業が増えると、時間あたりの金額は下がります。
  • この金額に、見積もり、打ち合わせ、仕事を探す時間は含まれていません。

実際の報酬と、かかる時間は、仕事の内容と依頼主で大きく変わります。調べた範囲では、プログラミング受託の報酬の分布を示した公的な資料は見つかりませんでした。

向いている人・向いていない人

向いている人

  • 依頼の内容を聞き取り、「どこまで作るか」を文面で確認することが苦にならない人
  • 作業時間を見積もり、納期を守って納品できる人
  • 契約書や、やり取りの記録を残すことができる人

向いていない人

  • 依頼主との確認や、仕様の変更への対応を、強く負担に感じる人
  • 短い期間で、決まった額の収入を得たい人
  • 契約書や条件を、読んで確かめる時間が取れない人

注意:損をしやすいポイント

  • 仕事を受ける前に、条件を文面で確認します。 ガイドラインによると、仕事を頼む事業者が明示する事項は、次の9つです。
  • 事業者と、フリーランスを識別できる名前
  • 業務委託をした日
  • 給付(作るもの)や、提供する仕事の内容
  • 給付を受け取る期日
  • 受け取る場所
  • 検査をする場合は、検査を終える期日
  • 報酬の額
  • 支払期日
  • 現金以外の方法で支払う場合の明示事項
  • 内容が決まらないことに正当な理由があるときは、決まった時点で直ちに明示する決まりです。 決まったあとの内容も、文面で残してください。
  • 契約の形を確認します。 「完成を約束する契約」か「作業をすることを約束する契約」かで、責任が変わります。準委任では完成義務を負わない形にもできますが、自分の契約がどちらなのかは、契約書の文言で確認してください。
  • 禁止されている行為があります。 ガイドラインによると、責めに帰すべき理由がないのに、受領の拒否、報酬の減額、返品をすることなどが挙げられています。また、通常より著しく低い報酬を不当に定めること(買いたたき)や、給付の内容を変更させたり、やり直しをさせたりして、利益を不当に害することも挙げられています。
  • これらの禁止行為は、1か月以上の業務委託などが対象です。 ガイドラインでは、特定業務委託事業者が、1か月以上の期間行う業務委託などをした場合とされています。自分の仕事が対象になるかは、公式の窓口で確認してください。
  • 作ったものの権利の扱いを、契約書で確認します。 文化庁の契約マニュアルには、著作権を依頼者に譲渡せず、作った人が持ったまま、利用を許諾する契約書例があります。この例は原稿の執筆の場合で、プログラムでの扱いは、この回は確認していません。納品したあとに、自分が何に使えるかも含めて、先に確認してください。
  • 報酬が、時間に見合わないことがあります。 計算例のように、追加の作業で時間あたりの金額が下がります。修正の回数と範囲を、先に決めておきます。
  • 「プログラミングで月〇〇万円」といった話は、成功した人の例です。 同じことをして同じ結果になる保証はありません。高額な講座や教材を売る話は、まず疑ってください。
  • 依頼主の情報の扱いに注意します。 依頼主から渡された資料やプログラムには、秘密にする約束がつくことがあります。他人のプログラムを、無断で使わないでください。
  • 税金に注意してください。 このページでは、金額の基準などは扱いません。国税庁の案内か税務署で確認してください。
  • 勤務先のルールを先に確認してください。 副業を禁止している会社では、始められないことがあります。

始め方

はじめての人は、いきなり大きな仕事を受けずに、小さな仕事で、条件の確認から練習します。

  1. 会社の就業規則を確認します。
  2. 自分で作った小さなツールやサイトを、見本として整理します。
  3. 小さな仕事に応募します。作る範囲、報酬の額、納期、支払期日、修正の回数を、文面で確認してから受けます。
  4. 作業時間を見積もり、報酬と比べます。
  5. 納品したら、かかった時間と手取りを記録します。
  6. 修正や追加が増えた原因を見直し、次の見積もりに生かします。

AIで自動化する

プログラミング受託は、コードを書く作業を、AIが手伝いやすい仕事です。一方で、依頼内容の確認や、動作の確認、納品は人が行います。

AIに任せやすいのは、次のような作業です。

  • コードの下書きや、テストの案の作成
  • 説明文や、納品時の手順書の下書き
  • エラーの原因の調べものの補助

人が必ず行うのは、次の作業です。

  • 依頼の内容と条件の確認、契約の確認
  • 動作の確認と、AIが書いたコードの確認
  • 納品と、依頼主とのやり取り

自動化についての注意点です。

  • 開発に使うAIサービスや、仕事を探すサービスの、公式のAPI(外部から操作するための窓口)の有無と、利用規約での扱いは、この回は確認していません。
  • 依頼主から渡された資料やプログラムを、AIのサービスに入力してよいかは、依頼主との契約と、サービスの規約で確認してください。
  • AIが書いたコードには、誤りや、動かない部分が混ざることがあります。納品の前に、人が動かして確認してください。

AIへの頼み方を具体的に知りたい人には、姉妹サイトの あんなことこんなことClaude(別サイト)があります。

こんなときは

  • 仕事が取れない。 見本を整理し直し、得意な分野(ウェブサイト、業務の自動化など)を絞って、応募の文面を見直します。
  • 修正や追加の依頼が、決めた範囲より多い。 先に確認した修正の回数と範囲を、文面で見直し、依頼主に伝えます。範囲を広げる場合は、報酬や納期の変更も、文面で確認します。
  • 報酬が支払われない、減らされた。 仕事の内容と報酬を確認した文面や、納品の記録を残して、依頼主に確認します。解決しないときは、仕事を探したサービスの窓口に相談します。
  • 時間あたりの報酬が低い。 1件にかかった時間を記録し、報酬と比べます。次の仕事から、見積もりを直します。

次に読む

同じ種類の手法と、損をしないための見分け方です。

  • Webライター企業やメディアから記事の執筆を請け負い、文字数や1本ごとの報酬を受け取る仕事。始めるのにお金はほとんどかかりませんが、時間あたりの収入が低くなることがあり、受ける前の条件確認が大切です。
  • 動画編集他の人が撮った動画を、カットや字幕、BGMなどでつなぎ直して納品する仕事。始める前に、報酬の決め方と、取引の条件を文書で確かめる決まりを知っておくことが大切です。
  • 怪しい稼ぎ話の見分け方SNSの広告やDMで届く「もうかる話」には、お金を先に払わせる、ふつうでない払い方を求める、といった共通の特徴があります。手を出す前の確認項目と、困ったときの相談先をまとめます。
