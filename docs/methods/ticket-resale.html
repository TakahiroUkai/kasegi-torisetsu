チケットの不正転売と、無許可の転売

人気公演のチケットを高く売る話や、SNSの「定価で譲ります」は、買う側にも売る側にも落とし穴があります。法律の要点と、買う前の確認手順、困ったときの相談先をまとめます。

結論から言うと、チケットは、主催者・正規のプレイガイド・公式リセールから買うのが基本です。SNSの個人間取引で先に送金すると、チケットも代金も戻らないことがあります。また、人気公演のチケットを定価より高く売ることは、法律で禁じられている場合があります。このページは、稼ぐ方法ではなく、買う側にも売る側にもなりうる人のための確認用の取扱説明書です。

しくみ

国民生活センターが挙げている、チケットの転売をめぐるトラブルは、主に次の4つです。

  • 転売仲介サイトで、高額なチケットや転売禁止のチケットと知らずに買い、キャンセルできない。
  • 公式の販売サイトだと思い込んで、海外の転売仲介サイトで買ってしまう。
  • 転売されたチケットが、主催者の規約で無効になり、本人確認で入場できないおそれがある。
  • 掲示板やSNSで「チケットを譲る」と買い手を集め、代金だけをだまし取られる。

2026年10月に国民生活センターが紹介した事例では、20歳代の女性がSNSの「定価で譲ります」という投稿に応じ、2人分で約2万円を送金しました。相手の運転免許証の画像を見て信用しましたが、送金後に連絡が取れなくなったということです。

売る側にも、注意が必要です。文化庁の資料によると、チケット不正転売禁止法は、2019年6月14日に施行されました(一部の規定を除く)。この法律の対象は、次の条件をすべて満たす「特定興行入場券」です(第2条)。

  • 興行主の同意のない有償譲渡の禁止が、販売時に明示されている。
  • 興行の日時・場所と、入場できる人または座席が指定されている。
  • 販売時に、入場できる人などの氏名と連絡先を確認する措置がとられ、そのことが表示されている。

そのうえで、興行主の事前の同意なく、業として、販売価格を超える価格で譲渡することが、不正転売として禁止されています(第3条)。不正転売を目的に、このチケットを買い取ることも禁止です(第4条)。

お金の流れ(手数料)

ふつうの買い物と違い、個人間の先払いでは、お金が出ていく一方で、戻る道筋がないことがあります。

  • チケット代そのもの。 定価、または定価を超えた価格を、先に送金します。
  • 転売仲介サイトでの価格と手数料。 国民生活センターは、購入前に価格・手数料・キャンセルのルールを確認するよう呼びかけています。
  • 入場できなかったときの損。 転売が禁止されているチケットを転売仲介サイトで買うと、入場できないおそれがあり、キャンセルできないこともあります(国民生活センター)。
  • 相手が現れなかったときの損。 国民生活センターが紹介した別の事例では、50歳代の女性が、転売仲介サイトで個人の出品者から約50万円(4人分、クレジットカード決済)のチケットを買いました。当日、会場での手渡しを約束しましたが、出品者は現れませんでした。サイトは、出品者と話すよう返信したということです。

売る側のお金の面では、不正転売には罰則があります。第9条によると、1年以下の懲役、または100万円以下の罰金、あるいはその両方です。

収益のイメージ(計算例)

この話題には、収益の見込みは書けません。代わりに、個人間の先払いで、チケットが届かなかった場合の損を、説明のための仮定で計算します。実際の事例ではありません。

  • 定価1万円のチケットを、2枚分、先に送金して買ったとします。
  • チケットは届かず、連絡も取れなくなり、お金は戻りませんでした。

チケットが届かなければ、公演に行く楽しみも失います。お金だけの問題ではありません。

見分けやすい人・気をつけたい人

だまされやすさは、性格や年齢では決まりません。国民生活センターの資料では、相談は20歳代の事例だけでなく、50歳代の事例も紹介されています。状況や気持ちの動き方で、誰にでも起こりえます。

見分けやすい人

  • 売り切れていても、いったん手を止めて、公式の販売元や公式リセールを確かめられる人
  • 相手の画像や言葉だけで信用せず、先払いを断れる人
  • 取引の前に、規約や運営事業者の所在地・連絡先を確認できる人

特に気をつけたい人

  • どうしても行きたい公演で、気持ちが焦っている人
  • 検索結果の上位に出たサイトを、公式の販売サイトだと思い込みやすい人
  • 行けなくなったチケットを、人気を理由に高く売れないかと考えている人

注意:損をしやすいポイント

  • 検索結果が転売仲介サイトのことがあります。 国民生活センターは、購入前に、公式の販売サイトかどうかを確かめるよう呼びかけています。
  • 転売仲介サイトを使うときは、先に規約を読みます。 主催者が転売を禁止していることがあり、その場合は入場できないおそれがあります。
  • SNSや掲示板での個人間取引は、大きなリスクがあります。 国民生活センターは、先に送金してチケットが届かない被害を紹介しています。
  • 相手の本人確認の画像があっても、安全の保証にはなりません。 事例では、免許証の画像を見て信用し、アプリの警告表示も見過ごして、被害にあっています。
  • 高く売る行為は、法律に違反するおそれがあります。 興行主の同意がなく、業として、販売価格を超えて譲ると、不正転売に当たりえます。どのチケットが対象かは、主催者に確認してください。
  • 定価での譲渡でも、主催者の決めた方法があります。 行けなくなったときは、主催者などの公式リセールの利用が案内されています。
  • この法律の対象外のチケットでも、主催者の規約で、転売が禁止されていることがあります。 法律に当たらなくても、入場できない場合があります。

始め方

「始める」というより、チケットを個人から買う話が来たときの確認の手順です。

  1. まず、公式の販売元を探す。 主催者、正規のプレイガイド、ファンクラブ、アーティストの公式サイトなどを確認します。
  2. 公式リセールがあるか確認する。 行けなくなった人向けに、主催者が用意していることがあります。
  3. 個人間なら、先払いを止める。 先に送金する取引は、いったん保留します。
  4. サイトの運営者を見る。 規約、運営事業者の所在地・連絡先が、はっきり書かれているかを確認します。
  5. 一人で決めない。 迷ったら、家族や友人、消費生活センターに話します。

こんなときは

  • もう送金してしまった。 それ以上は払わず、やり取りの画面、送金の控え、投稿のスクリーンショットを残します。そのうえで、消費者ホットライン「188」(最寄りの消費生活センターなどにつながります)や、警察相談専用電話「#9110」に相談します。
  • 転売仲介サイトで買ったが、入場できなかった。 消費者ホットライン「188」に相談します。
  • 自分のチケットが、法律の対象かどうか知りたい。 主催者に問い合わせます。法律そのものの質問は、文化庁の文化経済・国際課が窓口です(代表 03-5253-4111)。
  • 行けなくなったチケットを手放したい。 主催者の公式リセールなど、決められた方法があるか、主催者に確認します。

次に読む

ほかの手口も、あわせて確かめておくと見分けやすくなります。

  • 怪しい稼ぎ話の見分け方SNSの広告やDMで届く「もうかる話」には、お金を先に払わせる、ふつうでない払い方を求める、といった共通の特徴があります。手を出す前の確認項目と、困ったときの相談先をまとめます。
  • 闇バイト(高額バイトをうたう犯罪の勧誘)「高額」「即日」といった言葉で募集し、応募した人を強盗や詐欺の実行役にする犯罪の勧誘です。応募時に送った個人情報で脅されて抜けられなくなることがあります。見分け方と、応募してしまったときの相談先をまとめます。
  • SNS型投資詐欺の手口SNSの広告やダイレクトメッセージをきっかけに、投資の名目でお金を振り込ませる詐欺です。警察庁などの公表資料から、勧誘から被害までの流れ、払わされるお金、見分けるポイント、相談先をまとめます。
