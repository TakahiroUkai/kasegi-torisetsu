ハンドメイド販売

ハンドメイド販売は、自分で作ったアクセサリーや雑貨などを、minneやCreemaのようなマーケットに出して売る方法です。出品は無料で始められます。ただし、手数料は作品の代金だけでなく送料にもかかるため、手元に残る金額は思ったより少なくなります。向いているのは、作ること自体が好きで、材料費や時間を含めて採算を考えられる人です。短い期間で確実な収入がほしい人には向きません。

しくみ

  • 作品の写真と説明文、価格、送料を決めて、マーケットに出品します。買い手が代金を払うと、マーケットがいったん預かります。
  • 作品を梱包して発送すると、代金が売上金として自分の分になります。売上金の確定の条件や、振り込みの方法は、サイトごとに違うため、ヘルプで確認してください。
  • Creemaの公式ページによると、出店と出品の費用はかからず、売れたときに成約手数料がかかります。
  • 手数料の対象は、Creemaでは「作品+オプション+ラッピング+送料」の合計(決済総額)です。minneの表記でも、作品価格、購入オプション、送料の合計が対象です。

お金の流れ(手数料)

引かれるお金は、成約(販売)手数料と、振込手数料の2つです。次の数字は、各サイトの公式ページによるもので、変わることがあります。

  • Creemaの成約手数料: 作品・ヴィンテージ品・素材は、決済総額の10.67%(税込)です。2025年11月5日の注文から、送料も対象になりました。
  • Creemaの振込手数料: 売上の合計が3万円未満なら200円、3万円以上なら275円です(いずれも税込)。申請した翌営業日に受け取れるスピード振込は、別に振込対象額の3.56%(税込)がかかります。
  • minneの販売手数料: 作品価格・オプション・送料の合計に、約10.6%(税込)です。ただし、公式の2つのページで10.56%と10.659%に表記が分かれており、どちらが現行かは確認できませんでした。申し込む前に、最新のヘルプで確かめてください。
  • minneの振込手数料: 1回の振り込みにつき220円と書かれています。振り込みは月に1回、月末に〆た分を翌月末に払う形で、手数料は振り込むときに差し引かれます。このページには2020年の日付もあり、古い記述が残っている可能性があります。

Creemaの例です。作品2,000円に送料300円を足した決済総額2,300円が1件売れると、成約手数料は2,300円×10.67%で約245円です。送料の実費300円も自分が払うため、手元に残るのは約1,755円です。

収益のイメージ(計算例)

次の数字は仮定であり、実績ではありません。作品2,000円、送料300円(送料と実費が同じ)、材料費と梱包資材は1件あたり600円、Creemaで月に10件売れたとします。

  • 1件の手取りは、上の計算で約1,755円です。10件で17,550円になります。
  • 材料費と梱包資材は、600円×10件で6,000円です。
  • 月に1回、決済総額23,000円分(2,300円×10件)を振り込むと、3万円未満なので振込手数料は200円です。
  • 手元に残るのは、17,550円−6,000円−200円で、11,350円です。

1件に1時間かかるなら、10時間で11,350円になり、時給にすると約1,135円です(制作以外の撮影・梱包・やりとりの時間は含みません)。実際の売れる数や価格は、作品や写真の出来で大きく変わります。調べた範囲では、マーケット全体の売上の分布を示した公式の資料は見つかりませんでした。

向いている人・向いていない人

向いている人

  • 作ること自体が好きで、売れない時期があっても続けられる人
  • 材料費と手間を含めて、1件いくら残るかを計算できる人
  • 写真や説明文を、買い手に合わせて少しずつ直していける人

向いていない人

  • 短い期間で、決まった収入がほしい人
  • 梱包や発送、問い合わせへの返信を、負担に感じる人
  • 作ったものが売れないと、気持ちが続かない人

注意:損をしやすいポイント

  • 手数料は、送料にもかかります。 送料を安く見せても、手数料は決済総額で計算されます。価格を決めるときは、材料費と送料の実費を引いた手取りで考えてください。
  • 材料の在庫を先に買いすぎないでください。 売れる前に材料を大量に買うと、売れ残ったときに損になります。
  • 売上の「月○○万円」「年収○○万円」という話は、成功した人の例です。 同じことをして同じ結果になる保証はありません。
  • 「ハンドメイドで稼げる」と言って、高額な講座やコンサルを売る話は、まず疑ってください。 始めるのに、お金を払って教わる必要はありません。上の出典の公式情報で足ります。
  • 他の人の作品やキャラクターに似せたものは、避けてください。 既存のキャラクターやブランドのロゴを使った作品は、権利の問題になることがあります。各サイトの出品ルールを確認してください。
  • 税金に注意してください。 会社員の場合、副業の所得(売上から経費を引いた金額)が年間20万円を超えると、確定申告が必要になります。細かい扱いは、税務署か税理士に確認してください。
  • 勤務先のルールを先に確認してください。 副業を禁止している会社や、公務員のように営利目的の活動に制限がある立場では、始められないことがあります。

始め方

はじめての人は、1〜2か月かけて、少ない数の作品で試すと進めやすくなります。

  1. minneやCreemaなどの販売サイトを選んで、会員登録します。手数料や振込の条件は、登録の前に、最新のヘルプで確かめます。
  2. 作品を数点つくります。材料費は、1つあたりいくらかを記録しておきます。
  3. 作品の写真と説明文を用意します。大きさ、素材、制作にかかる日数、注意点を書いておくと、買い手が判断しやすくなります。
  4. 価格と送料を決めます。手数料と送料の実費、材料費を引いても残る金額で決めます。
  5. 出品して、閲覧数と購入数を見ながら、写真・説明・価格を直します。
  6. 売れたら、梱包して発送します。売上と経費は、その都度記録しておきます。

AIで自動化する

作品をつくる作業は人が行います。AIが役に立つのは、売るための文章や計算といった、まわりの作業です。

AIに任せやすいのは、次のような作業です。

  • 自分が書いたメモをもとにした、説明文やタイトル案の下書き
  • 手数料や送料の実費を引いた手取りの計算の確認
  • 問い合わせへの返信の下書き

人が必ず行うのは、次の作業です。

  • 作品をつくる、写真を撮る、梱包して発送する
  • 大きさ・素材などの事実と、手数料の数字を、公式の情報で確かめる
  • 価格を決める、公開してよいかを判断する、お客さんへ返信する

自動化についての注意点です。

  • minneやCreemaに、出品を自動化するための公式のAPI(外部から操作する窓口)があるかどうかは、確認できませんでした。確認できないうちは、出品は人が行うものとして考えてください。
  • 非公式な自動操作や、AIが書いた文章の扱いについての決まりは、各サイトの利用規約とヘルプで、始める前に確認してください。確認できていません。
  • AIの文章には、素材や大きさなどの事実の誤りが混ざることがあります。説明文は、必ず自分の目で作品と照らして確認してください。

AIへの頼み方を具体的に知りたい人には、姉妹サイトの あんなことこんなことClaude(別サイト)があります。

こんなときは

  • 見られているのに売れない。 写真の枚数と明るさ、説明文の情報、価格と送料の合計を見直します。同じ種類の作品と比べてみます。
  • そもそも見られない。 作品の数を少し増やして、題材や素材をそろえた作品の並びにすると、選びやすくなります。
  • 手取りが思ったより少ない。 手数料(送料にもかかります)、振込手数料、材料費を引いた金額で、もう一度計算します。

次に読む

同じ種類の手法と、損をしないための見分け方です。

  • せどり・転売安く仕入れた物を、フリマアプリなどで高く売って差額を得る方法。始める前に、古物商許可が要るかどうかを確かめることが大切です。
  • フリマアプリ家にある不用品を、フリマアプリで売る方法。メルカリの公式ヘルプをもとに、手数料を引いた手取り、売上金の振込、本人確認の流れをまとめます。
  • 怪しい稼ぎ話の見分け方SNSの広告やDMで届く「もうかる話」には、お金を先に払わせる、ふつうでない払い方を求める、といった共通の特徴があります。手を出す前の確認項目と、困ったときの相談先をまとめます。
