Instagram運用

写真やリールを投稿してフォロワーを増やし、ギフトや購読、企業との案件などで収入につなげる方法。始めるのは無料ですが、収益化の条件は公式で変わることがあり、収入になるまでの道のりは長めです。

Instagramは、写真や短い動画(リール)、ストーリーズを投稿して、フォロワーとつながるサービスです。投稿そのものはお金になりません。フォロワーや見る人が増えたあとで、ファンからの支援(ギフトや購読)、企業から頼まれる投稿(案件)、自分の商品やサービスへの案内などで、収入につなげます。

最初に知っておきたい点が2つあります。1つ目は、公式の収益化機能には条件があり、ギフトを受け取るには「プロアカウントで、18歳以上、フォロワー5,000人以上」などが必要と、2023年11月の発表に書かれています。2つ目は、企業から頼まれた投稿は、広告だと分かるようにするのが投稿する側の大事な作法だという点です。

しくみ

  • 個人のアカウントを、クリエイターアカウントまたはビジネスアカウント(プロアカウント)にして、投稿を続けます。
  • 収入につなげる道は、大きく3つあります。Instagramの機能で受け取る(ギフト、購読)、企業から案件をもらう、自分の商品やサービスの案内に使う、です。
  • ギフトは、見る人が「スター」を買って、リールなどに贈るしくみです。購読は、クリエイターが月額の料金を決め、登録した人だけが見られる投稿などを出すしくみです。どちらも日本で提供が始まったことが、Instagramの2023年の発表で確認できます。

お金の流れ(手数料)

Instagramの公式発表で確認できたお金に関する情報は、次の通りです。いずれも2023年の発表であり、今の条件は公式ヘルプで確かめてください。

  • ギフトのスターの価格(見る人が買うときの価格): 45スター70円、140スター430円、300スター860円の3種類です(2023年11月の発表)。
  • クリエイターの受け取り額: 「スターの数に応じて収益を得られる」と書かれているだけで、1スターあたりの金額や手数料の率は、確認できた範囲では見つかりませんでした。
  • 購読の料金: クリエイターが任意の月額料金を決めます。金額の上限と下限は、発表には書かれていませんでした。
  • 購読の使用料: Metaは2023年11月の発表で、2024年は購読の使用料を免除するとしていました。2025年以降の扱いは確認できませんでした。

企業の案件は、企業と投稿する人の間の契約で報酬が決まります。決まった相場はなく、公式の資料では確認できませんでした。

収入が出たときの税金や、受け取りの手続きは、始める前に公式ヘルプと税務署の案内で確かめてください。

収益のイメージ(計算例)

収入になるまでには、フォロワーを増やす時間がかかります。次の計算は、購読を例にした仮定の数字であり、実績ではありません。

  • 購読の月額を300円に決め、登録した人が20人いたと仮定すると、月の売上は6,000円です。
  • ここから、手数料(確認できなかった)と税金が引かれる可能性があります。手取りは、公式の条件を確かめてから計算してください。

この仮定は、購読する人が20人いる状態を前提にしています。フォロワーの数や、購読してくれる割合は、アカウントの内容で大きく変わります。調べた範囲では、日本のクリエイターの収入の分布を示した公式の資料は見つかりませんでした。

向いている人・向いていない人

向いている人

  • 写真や動画で、見る人の役に立つことや、好きなことを続けて発信できる人
  • 反応を見ながら、題材や見せ方を少しずつ変えられる人
  • 収入を得るまでに時間がかかることを、前提に始められる人

向いていない人

  • 短い期間で、決まった収入を得たい人
  • 投稿の反応が少ない時期に、続ける気持ちを保つのが難しい人
  • 企業の案件を受けるときの表示のルールや、契約の確認に手間をかけたくない人

注意:損をしやすいポイント

  • 収益化の条件は、変わることがあります。 この記事で確認できた条件は2023年の発表のものです。始める前に、Instagramの公式ヘルプで、今の条件と手数料を確かめてください。
  • フォロワーを買う、自動で増やすといったサービスに、お金を払わないでください。 本の題名や投稿にある「フォロワー〇万人」「月〇〇万円」は、成功した人の例です。同じことをして同じ結果になる保証はありません。
  • 「Instagramで稼げる」と言って、高額な講座やコンサルを売る話は、まず疑ってください。 始めるのに、お金を払って教わる必要はありません。
  • 企業から頼まれた投稿は、広告だと分かるようにしてください。 消費者庁は、令和5年10月1日から、広告であることを隠す「ステルスマーケティング」が景品表示法違反になるとしています。規制の対象は商品・サービスを供給する事業者(広告主)で、企業から依頼を受けたインフルエンサー等は規制の対象にならないと、同じページに書かれています。ただし広告には、企業が第三者に依頼する投稿も含まれます。表示の具体的なやり方は、消費者庁の運用基準とInstagramの公式ヘルプで確認してください(今回は確認できなかった)。
  • 他人の写真や音楽の無断利用は避けてください。 他の人が作った画像や音源には、権利があります。
  • 勤務先のルールを先に確認してください。 副業を禁止している会社や、公務員のように営利目的の活動に制限がある立場では、始められないことがあります。
  • 税金に注意してください。 副業の所得の扱いは、金額や働き方で変わります。細かい扱いは、税務署か税理士に確認してください。

始め方

はじめての人は、収入のことは後にして、まず「続けられる形」を作ります。次の順番で、1〜2か月かけて進めます。

次の図は、自作の図で、実際の画面ではありません。実際の画面とは、項目の名前も配置も違います。

  1. 何について投稿するかを、1つにしぼります。自分の経験や、調べたことなど、見る人の役に立つ題材を選びます。
  2. アカウントをプロアカウント(クリエイターまたはビジネス)に切り替えます。ギフトを受け取る条件にプロアカウントが含まれていると、2023年の発表に書かれています。
  3. プロフィールに、どんな内容を投稿するアカウントかを書きます。
  4. 投稿の頻度と型を決めます。まずは続けられる回数にします。
  5. 反応を見て、題材や見せ方を直します。
  6. 収益化の条件を、公式ヘルプで今の内容に確かめます。

投稿を公開する前の確認は、迷いやすい作業です。次の図で、確認する項目を整理します。この図は自作のイメージ図であり、実際のInstagramの画面ではありません。実際の画面とは、項目の名前も配置も違います。

AIで自動化する

投稿の準備の一部は、AIに任せることができます。ただし、Instagramで続けて見てもらえるのは、「自分の経験や、確かな情報」です。AI任せの内容は、他のアカウントと差がつきにくくなります。

AIに任せやすいのは、次のような作業です。

  • 題材の候補出し、投稿の構成案(1枚目に何を載せるか、など)づくり
  • 自分のメモをもとにした、キャプションの下書き
  • ハッシュタグの候補出し、反応の数字の集計

人が必ず行うのは、次の作業です。

  • 自分の経験や、伝えたい中身を用意する
  • 事実や数字を確かめる
  • 企業の案件のときの広告表示、公開してよいかの判断

自動化についての注意点です。

  • Meta for Developersの公式ページによると、プロアカウントへの投稿に使える公式のAPI(外部から投稿するための窓口)があります。投稿できる件数には上限があり、画像はJPEGのみなど、条件も書かれています。ページ内の上限の数字に食い違いがあったため、ここでは数字を載せません。
  • 同じページには、AIで生成したことを示す設定(is_ai_generated)もあります。AIで作った内容の表示については、公式ヘルプで確認してください。
  • Instagramの利用規約が、自動操作やAIの利用をどう扱っているかは、今回は確認できませんでした。始める前に、利用規約とコミュニティのルールを確認してください。
  • AIの文章には、事実の誤りが混ざることがあります。公開の前に、人が確認してください。

AIへの頼み方を具体的に知りたい人には、姉妹サイトの あんなことこんなことClaude(別サイト)があります。

こんなときは

  • 投稿しているのに、見られない。 題材をしぼれているか、最初の1枚目や冒頭の数秒で、何が分かる投稿かが伝わるかを見直します。
  • 企業から案件の連絡が来た。 契約の内容と報酬を文章で確認し、広告だと分かる表示の方法を、先に決めておきます。お金を先に払うよう求められた場合は、案件の話ではない可能性があります。支払いの前に、公的機関の相談窓口(消費者ホットライン188)に相談してください。
  • ギフトや購読の条件を満たしているか分からない。 公式ヘルプの、今の条件を確認します。この記事の条件は2023年の発表のものです。

次に読む

同じ種類の手法と、損をしないための見分け方です。

  • noteの有料記事文章を書いて値段をつけ、読者に買ってもらう方法。始めるのは無料ですが、売れる保証はなく、売上から1〜2割以上の手数料が引かれます。
  • ブログ(広告・アフィリエイト)記事を公開して、広告の表示やおすすめ商品の紹介から収入を得る方法。始めるのは無料でもできますが、収入は読まれる数に左右され、広告であることの表示など守る決まりもあります。
  • 怪しい稼ぎ話の見分け方SNSの広告やDMで届く「もうかる話」には、お金を先に払わせる、ふつうでない払い方を求める、といった共通の特徴があります。手を出す前の確認項目と、困ったときの相談先をまとめます。
