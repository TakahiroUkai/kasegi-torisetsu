LINEスタンプ

自分で描いたイラストをLINEスタンプにして、LINE Creators Marketで売る方法。始めるのは無料で、売上の分配率は公式の利用規約で50%と定められています。ただし、その前にアプリストアなどの手数料が引かれ、売れない場合もあります。

LINEスタンプは、LINE Creators Marketという場で、個人でも作って売ることができます。作る数は8個から40個まで(8・16・24・32・40個)で、画像を用意して審査に出し、通れば販売されます。売れた分は、LINEの定めた計算式で分配されます。

しくみ

  • スタンプの画像は、PNG形式で用意します。1個あたり最大で横370px×縦320px、容量は1MB以下です(公式のガイドラインによる)。
  • 画像のほかに、メイン画像(横240px×縦240px)と、トークルームタブ画像(横96px×縦74px)も必要です。
  • 画像は、背景を透明にし、偶数のサイズにします。ZIPファイルは60MB以下です。
  • 申請した画像は、LINEの審査を受けます。通ると販売できます。
  • 売れた分は、売上総額からプラットフォームごとの手数料を引き、その50%が分配されます(利用規約9.1。審査を初めて申請した日が2015年2月1日以降の場合)。

お金の流れ(手数料)

利用規約によると、お金の流れは次のとおりです。

  • プラットフォームごとの手数料: 売上総額から、まずこれが引かれます。金額(料率)は、今回確認した規約のページには書かれておらず、確認できませんでした。
  • LINEとの分配: 引いたあとの金額の50%がクリエイターの分配額になります。
  • 送金: 残高が1,000円を超え、請求したときに、請求から約45日以内に送られます。送金にかかる手数料や為替手数料は、クリエイターの負担です。
  • 税金: 源泉所得税などを引く必要がある場合は、分配額から引いた金額が支払われます。

販売価格の決め方は、今回確認した規約には載っていませんでした。画面で選べる価格は、登録時に公式の案内で確かめてください。

収益のイメージ(計算例)

次の数字は、すべて仮定です。実績ではありません。

  • 1か月の売上総額が10,000円、プラットフォームの手数料を仮に30%(3,000円)とします。
  • 引いたあとは7,000円で、その50%の3,500円が分配額です。
  • 残高が1,000円を超えれば、請求できます。実際には、送金手数料や税金が別にかかることがあります。

どれだけ売れるかを示した公式の資料は、調べた範囲では見つかりませんでした。

向いている人・向いていない人

向いている人

  • 絵を描くこと、またはキャラクターを考えることが好きな人
  • 規約や審査ガイドラインを読んで、直しながら進められる人
  • 売れなくても、まず1セット作ってみるつもりで続けられる人

向いていない人

  • 短い期間で、収入を得たい人
  • 審査で認められなかったときに、直す作業が負担になる人
  • 他人のキャラクターや有名人の似顔絵を使いたい人(審査で認められません)

注意:損をしやすいポイント

  • 売れないことは普通にあります。 お金はほとんどかかりませんが、作った時間が売上にならないことがあります。
  • 審査に通らないことがあります。 審査ガイドラインでは、権利の所在が明確でないもの(例:二次創作)、許諾のない人物の顔や似顔絵、特定の個人や法人への中傷、性的な表現、政治的な表現などが、認められない例として挙げられています。
  • 視認性も見られます。 スタンプのガイドラインでは、横長な画像や、8頭身のキャラクターの全身など、見にくいものがNG例とされています。
  • 手取りは、分配率の50%より少なくなります。 先に手数料が引かれ、送金手数料や税金もかかることがあります。
  • 「LINEスタンプで月〇〇万円」という話は、成功した例です。 同じことをして同じ結果になる保証はありません。「必ず売れる」と言って高額な教材や講座を売る話は、まず疑ってください。
  • 税金に注意してください。 会社員の場合、副業の所得が年間20万円を超えると、確定申告が必要になることがあります。細かい扱いは、税務署か税理士に確認してください。
  • 勤務先のルールを先に確認してください。 副業を禁止している会社では、始められないことがあります。

始め方

はじめての人は、最少の8個から作るのが進めやすい方法です。

  1. LINE Creators Marketの公式サイトで、登録の手順を確かめます。今回は、登録ページ(howto)は読めなかったため、画面の項目や流れは公式で確かめてください。
  2. 利用規約と審査ガイドラインを、先に読みます。
  3. 8個分の案を決めます。「ありがとう」「了解」のような、LINEのやり取りで使う場面から考えます。
  4. 絵を描いて、PNG形式で書き出します。サイズと容量はガイドラインに合わせます。
  5. 申請します。スタンプのタイトルは40文字以内、説明文は160文字以内です(全角は2文字として数えます)。
  6. 審査の結果を待ちます。

AIで自動化する

絵の案出しや下書きは、AIに手伝ってもらうことができます。ただし、申請と審査への対応は人が行います。

AIに任せやすいのは、次のような作業です。

  • 使う場面の案出し、セリフ(言葉)の候補づくり
  • タイトルや説明文の下書き
  • 画像のサイズや容量のチェック(スクリプトなど)

人が必ず行うのは、次の作業です。

  • キャラクターと絵の方向を決める
  • 審査ガイドラインに合っているかの確認
  • 申請と、審査結果への対応

自動化についての注意点です。

  • 利用規約8.13には、AIが生成した、または制作の過程でAIを使ったコンテンツである旨を、LINEが表示することがあると書かれています。申告に基づく場合のほか、LINEが判断した場合も含まれます。
  • 審査ガイドラインには、生成AIについての記述は見つかりませんでした。AIで作った画像を販売できる条件は、確認できませんでした。利用規約と審査ガイドラインを、始める前に確かめてください。
  • 申請を自動で行うための公式のAPIは、調べた範囲では確認できませんでした。

AIへの頼み方を具体的に知りたい人には、姉妹サイトの あんなことこんなことClaude(別サイト)があります。

こんなときは

  • 審査に通らなかった。 審査ガイドラインの禁止事項と照らし合わせます。権利、人物の顔、表現の3つが、見直す点になりやすいところです。
  • 売れない。 使う場面が伝わるスタンプか、タイトルと説明文が内容に合っているかを見直します。次のセットで試す方法もあります。
  • 分配額が思ったより少ない。 手数料、50%の分配、送金手数料、税金の順で、計算し直します。

次に読む

同じ種類の手法と、損をしないための見分け方です。

  • アプリの個人開発スマホアプリを自分で作ってストアで公開し、販売・課金・広告で収入を得る方法。作るのは1人でできますが、公開には登録費用と審査があり、ダウンロードされなければ収入はありません。
  • Kindle出版電子書籍を書いてAmazonのKindleストアで売る方法(KDP)。売れる保証はなく、ロイヤリティは35%または70%の2つから選びます。
  • 怪しい稼ぎ話の見分け方SNSの広告やDMで届く「もうかる話」には、お金を先に払わせる、ふつうでない払い方を求める、といった共通の特徴があります。手を出す前の確認項目と、困ったときの相談先をまとめます。
