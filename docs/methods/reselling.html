せどり・転売は、安く仕入れた物を、フリマアプリなどで高く売って差額を得る方法です。先に押さえたい点は2つです。自分の不用品を売るだけなら古物商許可は不要ですが、転売するために古物を買うなら許可が必要です。また、売れた金額の10%がメルカリの手数料として引かれ、送料と仕入れ代も差し引くと、手元に残る額は小さくなります。

しくみ

  • 商品を仕入れ、写真と説明文をつけて出品し、売れたら梱包して発送します。購入者が受け取って評価をすると、取引が完了します。
  • 仕入れ先は、店舗、ネット通販、リサイクルショップなどです。仕入れ値より高く売れる物を探します。
  • 愛知県警察のQ&Aによると、使用された物だけでなく、使用されていなくても使用のために取引された物は「古物」にあたります。古物を、売る目的で買い取るときは、古物商許可が必要です。
  • 次の場合は、許可は不要とされています。自分で使っていた物や、自分で使うために買った未使用の物を売る場合、自分で外国から買い付けて輸入して売る場合、全くの無償で引き取った物を売る場合です。ただし、転売目的で古物を買ったのなら、使っていないと言っても許可が必要です。

お金の流れ(手数料)

メルカリの公式ヘルプによると、費用は次のとおりです。

  • 販売手数料: 出品や登録は無料です。取引が完了したとき、販売価格の10%がかかります。
  • 振込手数料: 売上金を銀行口座に振り込むときに、一律200円です。お急ぎ振込を使うと、別に200円かかります。
  • 送料: 品物の大きさで変わります。この図では、仮定の金額を使います。
  • 仕入れ代: 売れ残ると、仕入れ代がそのまま損になります。

古物商許可を取る場合は、警視庁のページによると、申請手数料が19,000円です(東京都の場合。2025年9月5日更新のページによる)。ほかに、住民票の写しなど、書類の準備が必要です。

収益のイメージ(計算例)

次の数字は仮定であり、実績ではありません。仕入れ3,000円の品を5,000円で売り、送料を800円とします。

  • 販売手数料は5,000円の10%で、500円です。
  • 1個の利益は、5,000円−500円−3,000円−800円で、700円です。
  • 月に30個売れ、1回振り込んだとすると、利益は700円×30個で21,000円です。振込手数料200円を引いて、20,800円になります。
  • この金額に、仕入れに行く時間、写真を撮る時間、梱包の時間は含まれていません。売れ残った品の仕入れ代も含まれていません。

実際に何個売れるか、いくらで売れるかは、品物と時期で大きく変わります。調べた範囲では、せどり・転売の収益の分布を示した公的な資料は見つかりませんでした。

向いている人・向いていない人

向いている人

  • 商品の相場を調べて、仕入れる前に利益を計算するのが苦にならない人
  • 写真を撮る、説明文を書く、梱包して発送する作業を、続けられる人
  • 売れ残った場合の損を、小さな金額に抑えながら試せる人

向いていない人

  • 在庫を抱える不安が強く、売れ残りが気になって続けられない人
  • 許可や規約など、決まりを調べる作業を後回しにしがちな人
  • 短い期間で、決まった額の収入を得たい人

注意:損をしやすいポイント

  • 古物商許可が必要なのに取らないまま、転売を続けないでください。 転売目的で古物を買う場合は許可が必要です。無許可営業の罰則は、確認できたページに載っていませんでした。警察署の防犯係などで、始める前に確認してください。
  • 次の3つの質問で、許可が要るかを見ます。 (1)売る物は、自分で使っていた物か、自分で使うために買った物か。(2)全くの無償で引き取った物か。(3)自分で外国から買い付けて輸入した物か。どれにもあたらず、転売のために古物を買うなら、許可が必要です。判断に迷うときは、営業所を管轄する警察署に聞いてください。
  • 売れ残ると、仕入れ代が損になります。 一度にたくさん仕入れず、少ない数で売れ行きを確かめてください。
  • 手数料と送料を引くと、利益は小さくなります。 10%の手数料と送料を引いた手取りで、仕入れる前に計算してください。
  • メルカリには、出品できない物があります。 公式ヘルプによると、盗品など不正な経路で入手した物や、法令で許可が必要なのに許可なく出品する物は禁止です。禁止行為があると、取引のキャンセル、商品の削除、利用制限が行われることがあります。
  • 人気商品の取引が、急に禁止されることがあります。 報道によると、メルカリは2025年10月に取引の原則を改定し、転売のターゲットになって問題が急増しそうな商品の出品を、禁止できるようにしました。
  • 本の題名の「月収〇〇万円」は、成功した人の例です。 同じことをして同じ結果になる保証はありません。「転売で稼げる」と言って、高額な講座を売る話には、まず疑ってください。
  • 税金に注意してください。 国税庁によると、フリマアプリなどの個人取引による所得は、一般に雑所得にあたります。給与を1か所から受けている人は、給与以外の所得の合計が年間20万円を超えると、確定申告が必要です。生活の用に供している資産(古着や家財など)の売却による所得は非課税とされていますが、転売目的で仕入れた品はこの例にあたるとは限りません。税務署か税理士に確認してください。
  • 勤務先のルールを先に確認してください。 副業を禁止している会社では、始められないことがあります。

始め方

はじめての人は、仕入れる前に、許可の要否と費用の計算を済ませます。まず自分の不用品を1〜2個売って、出品から発送までの流れに慣れるのが近道です。

  1. 古物商許可が要るかを確認します。上の3つの質問で見て、迷うときは警察署に聞きます。会社の就業規則も確認します。
  2. 自分の不用品を、まず1〜2個出品します。写真の撮り方、説明文の書き方、梱包と発送の流れを体験します。
  3. 仕入れたい品の相場を調べます。売れた価格の例を見て、手数料と送料を引いた手取りで、利益が出るかを計算します。
  4. 売れ残っても痛くない金額で、少量を仕入れます。
  5. 出品して、売れたら発送します。仕入れ代、送料、手数料、売れた金額を、その都度記録します。
  6. 売れた品と売れ残った品を見直して、次の仕入れを決めます。年間の所得は、確定申告が必要かどうかの確認のために、記録を残します。

AIで自動化する

せどり・転売は、仕入れ、梱包、発送が人の作業です。AIに任せやすいのは、調べものや文章の下書きにとどまります。

AIに任せやすいのは、次のような作業です。

  • 出品文の下書き、タイトル案の作成
  • 売れた価格や仕入れ値の集計、利益の計算
  • 問い合わせへの返信の下書き

人が必ず行うのは、次の作業です。

  • 仕入れる品を選ぶ、実物の状態を確かめる
  • 古物商許可の要否や、出品禁止の物でないかの確認
  • 出品の公開、梱包、発送、最後の確認

自動化についての注意点です。

  • メルカリの公式ヘルプ「禁止されている行為」には、自動化やツールという言葉は載っていませんでした。ただし、利用規約の全文は確認できませんでした。公式のAPI(外部から出品や売上を扱うための窓口)の有無も、確認できませんでした。
  • 出品や発送のような、サービス上の操作を自動化するツールを使うなら、始める前に、利用規約とヘルプで確認してください。
  • 同じヘルプでは、事実と違う情報を書くことが禁止されています。AIが書いた出品文は、実物と合っているかを人が確かめてください。

AIへの頼み方を具体的に知りたい人には、姉妹サイトの あんなことこんなことClaude(別サイト)があります。

こんなときは

  • 売れ残っている。 同じ品の売れた価格の例と、自分の価格を比べます。写真と説明文の見直し、値下げ、出品の取り下げを検討します。仕入れ代を取り戻せないことも想定して、次の仕入れの数を減らします。
  • 利益が思ったより少ない。 販売手数料(10%)、送料、振込手数料(200円)を引いた手取りで、計算し直します。
  • 許可が要るか分からない。 営業所を管轄する警察署の防犯係に、品物と仕入れ方を伝えて確認します。
  • 盗品かもしれない品を見つけた。 購入せず、公式ヘルプの案内にある「商品の報告」を行います。

次に読む

同じ種類の手法と、損をしないための見分け方です。

  • フリマアプリ家にある不用品を、フリマアプリで売る方法。メルカリの公式ヘルプをもとに、手数料を引いた手取り、売上金の振込、本人確認の流れをまとめます。
  • noteの有料記事文章を書いて値段をつけ、読者に買ってもらう方法。始めるのは無料ですが、売れる保証はなく、売上から1〜2割以上の手数料が引かれます。
  • 怪しい稼ぎ話の見分け方SNSの広告やDMで届く「もうかる話」には、お金を先に払わせる、ふつうでない払い方を求める、といった共通の特徴があります。手を出す前の確認項目と、困ったときの相談先をまとめます。
