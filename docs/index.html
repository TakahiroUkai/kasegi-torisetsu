発信して稼ぐ

note、ブログ、動画、SNSなど、発信そのものを収入にする方法

  • noteの有料記事リスク自動化

    文章を書いて値段をつけ、読者に買ってもらう方法。始めるのは無料ですが、売れる保証はなく、売上から1〜2割以上の手数料が引かれます。

  • ブログ(広告・アフィリエイト)リスク自動化

    記事を公開して、広告の表示やおすすめ商品の紹介から収入を得る方法。始めるのは無料でもできますが、収入は読まれる数に左右され、広告であることの表示など守る決まりもあります。

  • YouTubeリスク自動化

    動画を投稿して、広告の表示などから収入を得る方法。投稿を始めるのは無料ですが、収益化には運営側の条件と審査があり、見られなければ収入はありません。

  • Instagram運用リスク自動化

    写真やリールを投稿してフォロワーを増やし、ギフトや購読、企業との案件などで収入につなげる方法。始めるのは無料ですが、収益化の条件は公式で変わることがあり、収入になるまでの道のりは長めです。

技能を提供して稼ぐ

文章、動画編集、開発、教えることなど、自分の技能を仕事にする方法

  • Webライターリスク自動化

    企業やメディアから記事の執筆を請け負い、文字数や1本ごとの報酬を受け取る仕事。始めるのにお金はほとんどかかりませんが、時間あたりの収入が低くなることがあり、受ける前の条件確認が大切です。

  • 動画編集リスク自動化

    他の人が撮った動画を、カットや字幕、BGMなどでつなぎ直して納品する仕事。始める前に、報酬の決め方と、取引の条件を文書で確かめる決まりを知っておくことが大切です。

作って売る

アプリ、素材、講座など、一度作ったものを売り続ける方法

  • アプリの個人開発リスク自動化

    スマホアプリを自分で作ってストアで公開し、販売・課金・広告で収入を得る方法。作るのは1人でできますが、公開には登録費用と審査があり、ダウンロードされなければ収入はありません。

仕入れて売る

物を仕入れて、または作って、売る方法

  • せどり・転売リスク自動化

    安く仕入れた物を、フリマアプリなどで高く売って差額を得る方法。始める前に、古物商許可が要るかどうかを確かめることが大切です。

  • フリマアプリリスク自動化

    家にある不用品を、フリマアプリで売る方法。メルカリの公式ヘルプをもとに、手数料を引いた手取り、売上金の振込、本人確認の流れをまとめます。

投資で増やす

働く時間ではなく、お金を働かせる方法

  • インデックス投資(積立)リスク自動化

    市場全体の動きに連動する投資信託を、少しずつ買い続ける方法。NISAを使うと運用益が非課税になりますが、元本は保証されず、働いて稼ぐ方法とは性質が違います。

怪しい話の見分け方

ここから先は、稼ぎ方ではありません。詐欺・違法行為・それに近い話を、見分けて避けるための解説です。

手を出す前に確認したい、危ない稼ぎ話の特徴

  • 怪しい稼ぎ話の見分け方リスク

    SNSの広告やDMで届く「もうかる話」には、お金を先に払わせる、ふつうでない払い方を求める、といった共通の特徴があります。手を出す前の確認項目と、困ったときの相談先をまとめます。

  • 闇バイト(高額バイトをうたう犯罪の勧誘)リスク

    「高額」「即日」といった言葉で募集し、応募した人を強盗や詐欺の実行役にする犯罪の勧誘です。応募時に送った個人情報で脅されて抜けられなくなることがあります。見分け方と、応募してしまったときの相談先をまとめます。

  • SNS型投資詐欺の手口リスク

    SNSの広告やダイレクトメッセージをきっかけに、投資の名目でお金を振り込ませる詐欺です。警察庁などの公表資料から、勧誘から被害までの流れ、払わされるお金、見分けるポイント、相談先をまとめます。

  • 口座の売買・貸し(口座を売ると犯罪になる)リスク

    「使っていない口座を買い取る」「口座を貸すだけ」といった話は、詐欺などの犯罪に口座を使わせる行為です。警察庁・金融庁・各県警などの公表資料から、勧誘から被害までの流れ、罰則、確認の手順、相談先をまとめます。

  • ネズミ講(無限連鎖講)リスク

    ネズミ講は、会員を増やしながら後から入った人のお金を先の人に配る仕組みで、法律で開設・運営・加入・勧誘のすべてが禁止されています。1回の勧誘でも違反になります。県警などの公表資料から、しくみ、罰則、マルチ商法との違い、確認の手順、相談先をまとめます。

  • 内職・副業詐欺(先にお金を払わせる型)リスク

    「仕事を紹介するので収入になる」と誘い、仕事に必要だとして先にお金を払わせる話があります。法律では業務提供誘引販売取引と呼ばれます。公的機関の資料から、しくみ、払わされるお金、確認の手順、20日間のクーリング・オフ、相談先をまとめます。

  • チケットの不正転売と、無許可の転売リスク

    人気公演のチケットを高く売る話や、SNSの「定価で譲ります」は、買う側にも売る側にも落とし穴があります。法律の要点と、買う前の確認手順、困ったときの相談先をまとめます。
