お金を払う前・払ってしまったあとの相談先

「先にお金を払えば稼げる」と言われたとき、すでに払ってしまったときに、何を確かめ、どこに相談するかを順番にまとめました。窓口の番号と受付時間は、2026年11月16日に公式ページで確認した内容です。変わることがあるため、かける前に公式ページでも確かめてください。

払う前に迷っているとき

  1. その場で払わない。「今日中」「残りわずか」と急かされても、返事は待ってもらえます。急かされること自体が、見直すきっかけになります。
  2. お金を払う相手と理由を、自分の言葉で言えるか確かめます。運営者の名前・住所・連絡先、何に対して払うのか、いつ何が受け取れるのかが書かれていなければ、先に進まないでください。
  3. 払い方を見ます。個人名義の口座への振込、電子マネーのコードを送る方法、暗号資産での支払いを求められたときは、立ち止まって相談してください。
  4. 1人で決めず、窓口に聞きます。消費者ホットライン「188」は、契約する前の相談もできます。

話の見分け方は、怪しい稼ぎ話の見分け方で、手口ごとの特徴は各ページで読めます。クイズで確かめることもできます。

お金を払ってしまったあと

  1. それ以上、払わない。「解約には手数料が要る」「被害を取り戻すために費用が要る」と、さらに払うよう求められても、応じる前に相談してください。
  2. 証拠を残す。やり取りの画面(メッセージ、広告、相手のアカウント名)、送金の控え、契約書や申込画面を、削除せずに保存します。
  3. 相手に個人情報を、これ以上渡さない。免許証や口座の情報をすでに送ったときは、そのことも相談時に伝えます。
  4. 早めに相談する。契約の種類によっては、契約を取り消せる期間が決まっています。期間や条件は契約ごとに違うため、窓口で確認してください。
  5. お金が戻るとうたう連絡に注意する。被害を取り戻すと持ちかける連絡が、新たな勧誘のことがあります。応じる前に、188や警察に相談してください。

ここに書いたのは一般的な進め方です。個別の事情で変わるため、法律上の判断が必要なときは、窓口や弁護士などの専門家に相談してください。

  • 消費者ホットライン「188」

    188に電話する

    最寄りの消費生活センターなどを案内する全国共通の番号です。相談は無料ですが、窓口につながった時点から通話料がかかります。

    受付時間: 受付時間は窓口ごとに異なります。土日祝日は、国民生活センターの休日相談(10時〜16時)も使えます(年末年始などを除く)。

    相談できること: 契約・支払いの前の迷い、払ってしまったあとの相談、どちらも。

    公式: 消費者庁「消費者ホットライン」

  • 警察相談専用電話「#9110」

    #9110に電話する

    緊急ではない相談を受け付ける短縮ダイヤルです。通常の通話料がかかります。いままさに被害に遭っているときは110番です。

    受付時間: 受付時間は都道府県の警察ごとに異なります。公式サイトで確認してください。

    相談できること: だまされたかもしれない、脅された、勧誘が続くなど。

    公式: 警視庁「相談ホットラインのご案内」
